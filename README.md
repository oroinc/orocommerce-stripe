# OroStripePaymentBundle

OroStripePaymentBundle adds the [Stripe](https://stripe.com/) payment integration to OroCommerce applications.

The bundle provides the Stripe Payment Element payment method, which admin users can enable and configure to let customers pay for their orders during checkout. It supports the authorize, charge, purchase, capture, cancel, confirm, refund and re-authorize payment actions, and manages Stripe webhook endpoints automatically from the integration settings.

For more information, please see the online [StripePaymentBundle documentation](https://doc.oroinc.com/bundles/extensions/StripePaymentBundle/).
